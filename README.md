# Замір натяжних стель

Офлайн-first PWA для замірників натяжних стель (MVP).

## Стек

React 18 · TypeScript · Vite · Tailwind · Zustand · Dexie · Zod · Vitest · vite-plugin-pwa

## Команди

```bash
npm install
npm run dev
npm run build
npm test
npm run lint
```

## Етапи

Див. `docs/ROADMAP.md` і `docs/DECISIONS.md`.
