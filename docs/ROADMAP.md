# Roadmap і точки розширення

## MVP (етапи 1–8)

1. Каркас проєкту (Vite/TS/Tailwind/PWA/тести)
2. Геометричне ядро + тести 4.4
3. Модель даних + Dexie + репозиторій + автозбереження
4. Екран «Приміщення»
5. Замовлення / список / шаблони кімнат
6. PDF / PNG / JSON + Web Share
7. Налаштування, тема, офлайн, Lighthouse, e2e
8. Фінальна перевірка DoD

## Після MVP — ліцензії для виробників

- **Той самий URL PWA** для всіх замірників (один фронтенд).
- Доступ, тарифи й ліцензії — **окремий бекенд** (не GitHub як база даних).
- Точка розширення: інтерфейс репозиторію в `src/data/` (IndexedDB → sync API без переписування UI).
- Перевірити на етапах 7–8: архітектура не блокує auth/ліцензії; у MVP їх немає.
- **Статус етапу 7:** `OrderRepository` порт і локальний IndexedDB не змішуються з UI — той самий URL PWA + майбутній бекенд ліцензій залишаються сумісними.

## Інші точки розширення (поза MVP)

| Тема | Як закласти зараз |
| --- | --- |
| Синхронізація з виробництвом | Репозиторій + JSON export/import |
| Bluetooth-рулетки | Шар введення вимірів відокремлений від геометрії |
| Розкрій / кошторис | Окремі модулі; не змішувати з `core/geometry` |
| Криві / багаторівневі стелі | Модель `Room` / `Fixture` розширювана; MVP лише прямолінійний багатокутник |
| CRM / оплати | Зовнішній бекенд; локальні замовлення залишаються джерелом правди офлайн |
